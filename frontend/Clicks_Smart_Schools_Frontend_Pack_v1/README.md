# Clicks Smart Schools — Frontend Development Pack v1.0
**Scope:** Public website PUB-001–PUB-013, including school registration, authentication, responsive layouts and supporting states.
**Owner/brand:** Clicks Technology Limited. **Product:** Clicks Smart Schools.
**Status:** Implementation handoff. The UI mockups are approved visual direction, **not executable specifications**; legal copy, pricing, security claims, contact details, images and API contracts need verification.

## Start here
1. Read `AGENTS.md`, `docs/01-PRODUCT-AND-SCOPE.md`, `docs/02-DESIGN-SYSTEM.md`, and `docs/03-PAGE-REGISTER.md`.
2. Review `references/` screenshots (visual inspiration only, not production image assets).
3. Connect the real Laravel OpenAPI spec before implementing server-integrated registration/auth.
4. Execute `docs/07-IMPLEMENTATION-PLAN.md` in sequence, update `tracker.md` on every task.
5. Use `docs/10-CODEX-PROMPTS.md` to initiate and continue Codex sessions.

## Folder map
- `AGENTS.md`: mandatory Codex engineering rules.
- `docs/`: product, design, screens, APIs, security, SEO, QA, plan, prompts, skills, acceptance and deployment.
- `references/`: selected previously generated UI concept images; may contain fictional content.
- `assets/`: asset manifest, provisional brand mark, favicon, illustrative SVGs, licensing instructions.
- `starter/`: minimal Next.js App Router TypeScript source example (not a complete implemented application).
- `tracker.md`: actionable checklist.

## Critical distinction
The user approved the visual direction and page sequence. This does NOT approve any speculative API route, subscription price, Google SSO, trial, testimonial, company metric, legal clause, privacy promise, support schedule or email/phone number shown in image mockups. Use approved copy only; otherwise use explicit content TODOs.
