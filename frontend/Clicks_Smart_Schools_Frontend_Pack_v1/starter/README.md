# Minimal Next.js starter reference
This folder is a **reference starter**, not the completed public website. To use:
1. Create a new Next.js App Router app with TypeScript, Tailwind, ESLint and `src/` directory.
2. Merge `src/` into the generated app and install `lucide-react` if required.
3. Add shadcn/ui components, React Hook Form, Zod, TanStack Query, Vitest, Playwright and CI according to the implementation plan.
4. Replace the provisional logo with official assets and build the page slices.

The starter deliberately does not implement API-dependent flows or make up API contracts.
